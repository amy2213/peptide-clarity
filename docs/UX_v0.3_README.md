# Peptide Clarity: audience-first UX concept v0.3

**Working, owner-led INTERNAL UX prototype. This is NOT an expert-reviewed publication or a supplier certification.**

## What's different from v0.2
- Homepage now asks one question and offers just **Understand It, Verify It, Compare the Evidence**.
- Technical editorial workbench and source ledger are removed from visitor navigation; research citations remain beside the relevant findings.
- Inline 'What does this actually mean?' explainers in the substance, COA, and comparison experiences.
- Three draft substance profiles retained from v0.2, including 11 primary-source records / 11 claims; their content has not received professional expert review.
- Supplier comparison uses clearly fictional example cases, not unreconciled real-vendor allegations.
- No COA upload, authentication, dosing, vendor purchase link, AI-generated certification or medical recommendation.

## How to use
Open `index.html` in a modern web browser. The prototype is one self-contained file with embedded starter data. This version uses no backend or accounts.

## The existing public GitHub Pages site
Do **not** overwrite `main` / the live GitHub Pages site with this draft without a documented owner decision and suitable safety reviews. A feature branch is safe for source-code review but still publicly readable if the repository is public.

## Scope warning
- 'Research snapshot: October 24, 2026' is not a claim that sources have been continually updated.
- Research statuses are editorial summaries pending qualified scientific/medical/regulatory review.
- FDA approval applies to specific drug products and indications.
- Evidence-stage cards are study categories, not an approval ladder.
- Missing test results are not proof of success or failure; lab document correspondence is not human safety.
- Design QA is not WCAG 2.2 AA compliance verification.
